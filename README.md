# Stophone · 랜딩 페이지

자녀 스마트폰의 취침 시간, 하루 사용 시간, 차단 앱을 관리하는 안드로이드 앱의 소개 페이지입니다.

- 가격: $50 한 번 결제, 영구 사용
- 체험: 7일 무료 체험 (앱 쪽 체험 기능은 아직 구현 전, 아래 확인 필요 참고)

## 구성

- `index.html`: 랜딩 페이지 전체
- `styles.css`: 랜딩 전용 스타일
- `tokens/tokens.css`, `tokens/base.css`: 공통 디자인 키트 (라이트/다크 토큰, 버튼, 표, 제품 화면)
- `icon.svg`: 파비콘

빌드 과정은 없습니다. 파일을 그대로 정적 호스팅에 올리면 됩니다.

## 열기 전에 채울 것 (확인 필요)

- 결제 버튼: 레몬스퀴지 체크아웃 링크를 `index.html`의 `#price` 버튼에 연결하고 `disabled`를 빼세요.
- APK 다운로드 링크와 QR: 구매 후 전달 방식을 정한 뒤 추가하세요.
- 사업자 정보, 이메일, 개인정보 처리방침, 환불 정책, 기기 수 제한, 업데이트 정책.

## 앱과 맞춰야 할 것

- "7일 무료 체험"은 앱에 체험 기간 기능이 있어야 사실이 됩니다. 현재 APK에는 체험 기간 로직이 없습니다. 체험 기능을 넣기 전까지 이 문구는 출시 전에 수정하거나 기능을 먼저 구현해야 합니다.
- 앱 안의 이름은 아직 "타임가드"입니다. 이 페이지는 "Stophone"으로 썼습니다. 앱 이름을 Stophone으로 바꿀지 정해 주세요.
- 앱의 한계(삭제 차단 불가, Android 전용, 접근성 정책)는 페이지의 "알아 두실 점"과 푸터 고지에 적혀 있습니다.
